# PreScan

Plateforme d'aide au dépistage des anomalies cérébrales fœtales à partir d'images d'échographie prénatale, réservée à des médecins authentifiés.

> Ce résultat est une aide au dépistage et doit être confirmé par un professionnel de santé.
